Sobre:

  1. De forma geral, o objetivo desta tela é comparar os números do SUAP com os números do SOU GOV.
  2. "Dados do SUAP enviados pela API": consideram os dados preparados para envio pela API (Gestão e Comissões > API > Participantes). Assim, considera os dados enviados pela API e estes eventualmente podem ser diferentes dos dados do SUAP. Por fim, cabe ressaltar que os dados da API podem ser diferentes dos dados do SUAP devido à periodicidade de preparação e envio dos dados.
  3. É importante que esses números estejam iguais. Eventuis diferenças podem ser resolvidas com ajujstes diretamente no SUAP ou no SIAPE.
  4. A quantidade de servidores em PGD deve ser iguais considerando os dados "Dados do SUAP", "Dados do SUAP enviados pela API" e "Dados do SOU GOV (SIAPE)".
