# Especificação do Módulo RSC-TAE

## Referência Normativa

**Relatório Técnico CNS Nº 01/2026** — Subsídios para regulamentação do Reconhecimento de Saberes e Competências (RSC) para o PCCTAE, conforme Lei nº 11.091/2005 e Termo de Acordo nº 11/2024.

---

## 1. Visão Geral

O RSC-PCCTAE (Reconhecimento de Saberes e Competências do Plano de Carreira dos Cargos Técnico-Administrativos em Educação) é um processo pelo qual servidores técnico-administrativos das IFEs podem obter o Incentivo à Qualificação (IQ) por meio da comprovação de saberes e competências adquiridos na experiência profissional, como alternativa à titulação formal.

### 1.1 Base Legal
- **Lei nº 11.091/2005** (PCCTAE) — arts. 3º, 8º, 11, 12-A a 12-F
- **Termo de Acordo nº 11/2024** — cláusula quarta
- **Decreto regulamentador** (minuta — Anexo I do Relatório CNS 01/2026)

---

## 2. Níveis de Concessão (Art. 3º, §1º)

O RSC-PCCTAE pode ser concedido em **6 níveis**, com pontuação mínima e número mínimo de itens:

| Nível          | Pré-requisito (Escolaridade) | Pontuação Mín. | Nº Mín. Itens | IQ Correspondente |
|----------------|------------------------------|----------------|---------------|-------------------|
| RSC-PCCTAE-I   | Fundamental Incompleto       | 10 pontos      | 2 itens       | IQ Fund. Completo (10%)   |
| RSC-PCCTAE-II  | Fundamental Completo         | 20 pontos      | 3 itens       | IQ Médio (20%)            |
| RSC-PCCTAE-III | Médio/Técnico                | 25 pontos      | 4 itens       | IQ Graduação (25%)        |
| RSC-PCCTAE-IV  | Graduação                    | 30 pontos      | 5 itens       | IQ Especialização (30%)   |
| RSC-PCCTAE-V   | Pós-graduação                | 52 pontos      | 8 itens       | IQ Mestrado (52%)         |
| RSC-PCCTAE-VI  | Mestrado                     | 75 pontos      | 12 itens      | IQ Doutorado (75%)        |

### 2.1 Regras dos Níveis
- **Cumulatividade** (§2º): A pontuação reconhecida tem caráter cumulativo. O saldo não aproveitado será utilizado em concessões futuras.
- **Interstício** (§3º): 3 anos entre requerimentos, contados da última concessão.
- **Temporalidade** (Art. 9º): Podem ser consideradas atividades a qualquer tempo, inclusive durante estágio probatório.

## 5. Fluxo do Processo (Arts. 7º a 14)

```
[Servidor]                    [CRSC-PCCTAE]              [Autoridade]
    |                              |                          |
    |-- 1. Abre requerimento ----->|                          |
    |   (memorial + docs +         |                          |
    |    formulário + declaração)  |                          |
    |                              |                          |
    |-- 2. Envia doc. preliminar ->|                          |
    |   (diploma/certificado)      |                          |
    |                              |                          |
    |                    3. Valida documento -------.          |
    |                       preliminar              |         |
    |                              |                |         |
    |<--- 3a. Solicita correção ---|                |         |
    |     (se necessário)          |                |         |
    |                              |                |         |
    |                    4. Define avaliadores       |         |
    |                              |                |         |
    |                    5. Análise de mérito        |         |
    |                       (max 120 dias)          |         |
    |                              |                |         |
    |                    6. Parecer conclusivo       |         |
    |                       (mín 3 membros,         |         |
    |                        paridade)              |         |
    |                              |                |         |
    |                              |-- 7. Emite ato --------->|
    |                              |    administrativo        |
    |                              |                          |
    |<---- Deferido/Indeferido ----|                          |
    |                              |                          |
    | (Recurso - Lei 9.784/99) --->|                          |
```

### 5.1 Estados do Processo

| # | Estado (`SituacaoProcesso`) | Valor | Descrição |
|---|----------------------------|-------|-----------|
| 1 | `AGUARDANDO_PREENCHIMENTO` | 1 | Servidor preenche memorial e itens |
| 2 | `AGUARDANDO_VALIDACAO_DOCUMENTO_PRELIMINAR` | 6 | Documento preliminar (diploma) aguardando validação |
| 3 | `AGUARDANDO_CORRECAO` | 7 | Documento com correção solicitada — servidor corrige e reenvia |
| 4 | `AGUARDANDO_AVALIADOR` | 2 | Documento validado, aguardando designação de avaliadores pelo RH |
| 5 | `AGUARDANDO_ACEITE_AVALIADOR` | 8 | Avaliadores designados, aguardando aceite de todos |
| 6 | `EM_ANALISE` | 3 | Todos os avaliadores aceitaram — análise em andamento |
| 7 | `DEFERIDO` | 4 | Processo aprovado (média ≥ pontuação mínima do nível) |
| 8 | `INDEFERIDO` | 5 | Processo negado (decisão fundamentada, cabível recurso) |

#### Transições válidas

```
AGUARDANDO_PREENCHIMENTO
    → AGUARDANDO_VALIDACAO_DOCUMENTO_PRELIMINAR  (servidor conclui preenchimento)
    → AGUARDANDO_AVALIADOR                       (se doc. preliminar já validado)

AGUARDANDO_VALIDACAO_DOCUMENTO_PRELIMINAR
    → AGUARDANDO_CORRECAO                        (RH solicita correção do doc.)
    → AGUARDANDO_AVALIADOR                       (RH valida o doc. preliminar)

AGUARDANDO_CORRECAO
    → AGUARDANDO_VALIDACAO_DOCUMENTO_PRELIMINAR  (servidor resubmete doc. corrigido)

AGUARDANDO_AVALIADOR
    → AGUARDANDO_ACEITE_AVALIADOR                (RH designa avaliadores)
    → AGUARDANDO_CORRECAO                        (RH devolve para correção)

AGUARDANDO_ACEITE_AVALIADOR
    → AGUARDANDO_ACEITE_AVALIADOR                (avaliador aceita mas outros ainda pendentes)
    → EM_ANALISE                                 (todos os avaliadores aceitaram)
    → AGUARDANDO_AVALIADOR                       (qualquer avaliador recusa)
    → AGUARDANDO_CORRECAO                        (RH devolve para correção)

EM_ANALISE
    → DEFERIDO                                   (todos avaliadores finalizaram; média ≥ mín.)
    → INDEFERIDO                                 (todos avaliadores finalizaram; média < mín.)
    → AGUARDANDO_CORRECAO                        (RH devolve para correção)
```

### 5.2 Regras do Processo
- **Vedação de duplicidade** (Art. 7º, §2º): Cada fato só pode ser computado uma única vez, vedada duplicidade entre eixos/itens — prevalece o de maior pontuação.
- **Fluxo contínuo** (Art. 10): O requerimento tramita em fluxo contínuo.
- **Documentação alternativa** (Art. 15): Na falta de registro formal, aceita-se declaração de outro servidor ou autodeclaração com documentos comprobatórios.
- **Prazo de análise** (Art. 6º, II): Máximo de 120 dias após protocolar.

### 5.3 Composição da CRSC-PCCTAE (Arts. 4º–6º)
- Integrantes da carreira PCCTAE, paritários entre:
  - Gestão de pessoas da IFE
  - Entidades sindicais
  - Comissões Internas de Supervisão (CIS)
- Mínimo 3 membros na manifestação do parecer
- Pode ser descentralizada por campi

---

## 6. Memorial (Art. 11)

O memorial deve apresentar:
- Descrição das atividades vinculadas aos requisitos (incisos I a VI)
- Demonstração de que a trajetória se alinha ao padrão de competências do nível pleiteado

---

## 7. Requerimento (Anexo IV)

O formulário de requerimento contém:
1. **Identificação do servidor** (nome, SIAPE, cargo, nível de classificação, lotação)
2. **Informações do requerimento** (nível pretendido, pontuação mínima, pontuação apresentada, nº de critérios, saldo/banco de pontos, referência a concessão anterior)
3. **Declaração de conformidade legal** (assinatura do servidor)
4. **Memorial** (trajetória e contribuições)
5. **Descrição das atividades por requisito** (tabela por critério I a VI)
6. **Conclusão do servidor**

| **G3 — Atualização das pontuações dos 89 itens** | As pontuações na fixture atual NÃO correspondem às do Anexo II/III. Ex: Item 1 (gestão de contratos) está com 0.100 mas deveria ser 0.30 (Req IV, Grupo 2). | **ALTO** — Dados incorretos |
| **G4 — Saldo de pontos (banco de pontos)** | Art. 3º, §2º prevê cumulatividade e banco de pontos de concessões anteriores. Não há campo `saldo_pontuacao_anterior` no processo. | **MÉDIO** — Funcionalidade nova |
| **G5 — Interstício de 3 anos** | Art. 3º, §3º: Não há validação de interstício de 3 anos entre concessões. | **MÉDIO** — Validação |
| **G6 — Vedação de duplicidade entre eixos** | Art. 7º, §2º: Cada fato pode ser computado uma única vez, vedada duplicidade entre eixos/itens. Sem controle atual. | **MÉDIO** — Regra de negócio |
| **G7 — Memorial do servidor** | Arts. 10–11: O modelo atual não tem campo para memorial textual do servidor. | **MÉDIO** — Campo novo |
| **G8 — Declaração de conformidade** | Art. 10, IV: Não há campo de declaração formal do servidor. | **BAIXO** — Campo novo |
| **G9 — Prazo de 120 dias para análise** | Art. 6º, II: Não há controle/alerta de prazo de 120 dias para a CRSC. | **BAIXO** — Funcionalidade nova |
| **G10 — Itens temporais não marcados** | Vários itens que usam "Tempo (mês)" como unidade (itens 23, 46, 49, 51, 52, 53, 55, 57, 58, 60, 68, 69, 70) estão com `item_temporal=False`. | **ALTO** — Dados incorretos |
| **G11 — Documentação comprobatória alternativa** | Art. 15: Aceitar declaração de outro servidor ou autodeclaração como comprovação alternativa. | **BAIXO** — UX |
| **G12 — Configuração de período de submissão** | Art. 14: Prazo de 30 dias para instalação. Necessidade de controlar período de abertura de processos. | **BAIXO** — Configuração |
| **G13 — Fixture com dados incorretos** | A fixture `initial_data_saber_competencia.json` contém mapeamentos errados: os 89 itens não correspondem ao Anexo III do regulamento. Os itens 22–53 têm números/grupos/descrições completamente distintos do PDF. Itens de Req I, Req IV e Req VI estão misturados no Req II. A fixture precisa ser completamente recriada conforme a Seção 4 desta especificação (corrigida). | **ALTO** — Dados incorretos |
| **G14 — Pré-requisito de escolaridade por nível** | O regulamento exige escolaridade mínima para pleitear cada nível (ex: RSC-I exige Fundamental Incompleto, RSC-VI exige Mestrado). Não há validação dessa regra no processo de abertura. | **MÉDIO** — Validação |

## 9. Conclusão da Análise

O módulo existente **já é bastante completo** e a arquitetura geral está bem alinhada com o regulamento. As mudanças necessárias **não são drásticas** — o principal ajuste é **estrutural no modelo de dados**: adicionar campos `requisito` e `grupo` ao `RolSaberCompetencia` e atualizar o fixture com as pontuações corretas do regulamento. O fluxo de processo, avaliação multi-avaliadores, upload de documentos e relatórios já estão implementados conforme a norma.

A estimativa de impacto:
- **Modelos**: Alteração em 2 modelos (`RolSaberCompetencia` + `ProcessoRSCTae`) e criação de 0 modelos novos
- **Fixture**: Completa atualização do `initial_data_saber_competencia.json` (89 itens com requisito/grupo/pontuação correta)
- **Views/Admin**: Ajustes menores para exibição por requisito/grupo e validações de interstício
- **Migrações**: 1 nova migração para os novos campos
