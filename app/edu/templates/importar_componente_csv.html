Tipo
Obrigatório
Descrição
Matriz.id Inteiro {{ "Sim"|status }} Identificador da Matriz. Será a chave para vincular os componentes à matriz.
Componente.ativo Booleano {{ "Sim"|status }} Indica se o componente está ativo para ser vinculado em matriz.
Componente.descricao Texto {{ "Sim"|status }} Nome do componente
Componente.ch_hora_relogio Inteiro {{ "Sim"|status }} Carga horária hora/relógio do componente.
Componente.ch_hora_aula Inteiro {{ "Sim"|status }} Carga horária hora/aula do componente. Campo do tipo inteiro.
Componente.ch_qtd_creditos Inteiro {{ "Sim"|status }} Quantidade total de créditos do componente
Componente.nivel_ensino_id Inteiro {{ "Sim"|status }} Nível de ensino de componente. Valores permitidos:
1: Fundamental
2: Médio
3: Graduação
4: Pós Graduação
Componente.tipo Texto {{ "Sim"|status }} Tipo do componente. Este campo deve ser uma abreviatura que pode indicar o tipo do componente. Por exemplo, LIC (componentes de licenciatura) TIN (componentes de técnico integrado).
Componente.sigla_legado Texto {{ "Não"|status }} Sigla ou código de identificação único do componente no sistema legado. Se o campo não for informado não será possível importar a configuração de pré e co-requisitos da matriz
Componente.observacao Texto {{ "Não"|status }} Observação do componente
Componente.abreviatura Texto {{ "Não"|status }} Abreviatura do componente
ComponenteCurricular.optativo Booleano {{ "Sim"|status }} Indica se o componente é optativo
ComponenteCurricular.tipo Inteiro {{ "Sim"|status }} Tipo do componente curricular. Valores permitidos:
1: Regular
2: Seminário
3: Prática Profissional
4: Trabalho de Conclusão de Curso
5: Atividade de Extensão
ComponenteCurricular.qtd_avaliacoes Inteiro {{ "Sim"|status }} Quantidade de etapas/avaliações do componente curricular na matriz. Valores permitidos:
0: nenhuma avaliação
1: Uma avaliação
2: Duas avaliações
3: Três avaliações
4: Quatro avaliações
ComponenteCurricular.nucleo Texto {{ "Sim"|status }} Núcleo vinculado ao componente curricular
ComponenteCurricular.ch_presencial Inteiro {{ "Sim"|status }} CH de aula presencial/teórica do componente.
Atenção: A soma da CH dos 4 campos (ch_presencial, ch_pratica, ch_extensao, ch_pcc) precisa ser exatamente a CH (Componente.ch_hora_relogio) do componente.
ComponenteCurricular.ch_pratica Inteiro {{ "Sim"|status }} CH de aula prática do componente.
Atenção: A soma da CH dos 4 campos (ch_presencial, ch_pratica, ch_extensao, ch_pcc) precisa ser exatamente a CH (Componente.ch_hora_relogio) do componente.
ComponenteCurricular.ch_extensao Inteiro {{ "Sim"|status }} CH de atividade de extensão do componente.
Atenção: Para componentes do tipo Atividade de Extensão informar a CH somente no campo ComponenteCurricular.ch_presencial.
Atenção: A soma da CH dos 4 campos (ch_presencial, ch_pratica, ch_extensao, ch_pcc) precisa ser exatamente a CH (Componente.ch_hora_relogio) do componente.
ComponenteCurricular.ch_pcc Inteiro {{ "Sim"|status }} CH de Prática como Componente Curricular
Atenção: Caso não seja informado, assumirá o valor zero.
Atenção: A soma da CH dos 4 campos (ch_presencial, ch_pratica, ch_extensao, ch_pcc) precisa ser exatamente a CH (Componente.ch_hora_relogio) do componente.
ComponenteCurricular.avaliacao_por_conceito Booleano {{ "Sim"|status }} Indica se o componente curricular será avaliado por conceito. Informar Falso para avaliação por nota.
ComponenteCurricular.segundo_semestre Booleano {{ "Sim"|status }} Informar apenas para matrizes anuais (4 etapas) e que o componente, de 2 etapas, ocorra no segundo semestre do ano letivo.
ComponenteCurricular.pode_fechar_pendencia Booleano {{ "Sim"|status }} Utilizado por componentes que podem finalizar em data posterior ao fechamento do período letivo, por exemplo, componentes do tipo Prática profissional.
ComponenteCurricular.periodo Inteiro {{ "Depende"|status }} Período que o componente é ofertado na matriz. Deve ser vazio (sem período) se o componente for optativo.
Atenção: preenchimento obrigatório apenas para componente não optativo. Não pode ser preenchido para componente optativo.
ComponenteCurricular.ch_semanal_1s Inteiro {{ "Depende"|status }} Informa a quantidade de aulas semanais que haverá no 1° semestre do componente de um componente de 4 etapas.
Atenção: Obrigatório para componentes de 4 etapas, se a quantidade de aulas no primeiro semestre for diferente da quantidade do segundo semestre. Caso contrário não informar.
Atenção: Não informar valor se quantidade de etapas do componente for menor que 4.
ComponenteCurricular.ch_semanal_2s Inteiro {{ "Depende"|status }} Informa a quantidade de aulas semanais que haverá no 2° semestre do componente de um componente de 4 etapas.
Atenção: Obrigatório para componentes de 4 etapas, se a quantidade de aulas no primeiro semestre for diferente da quantidade do segundo semestre. Caso contrário não informar.
Atenção: Não informar valor se quantidade de etapas do componente for menor que 4.
ComponenteCurricular.pre_requisitos Lista {{ "Não"|status }} Informar os componentes que são pré-requisitos deste componente.
Atenção: Lista separada por vírgula do valor informado na coluna “Componente.sigla_legado” dos componentes importados antes deste registro.
ComponenteCurricular.co_requisitos Lista {{ "Não"|status }} Informar os componentes que são co-requisitos deste componente.
Atenção: Lista separada por vírgula do valor informado na coluna “Componente.sigla_legado” dos componentes importados antes deste registro.
