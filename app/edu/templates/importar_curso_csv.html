CursoCampus.ativo Booleano {{ "Sim"|status }} Indica se o curso está ativo.
CursoCampus.suspenso Booleano {{ "Sim"|status }} Indica se o curso está suspenso temporariamente para novos ingressantes.
CursoCampus.em_extincao Booleano {{ "Sim"|status }} Indica se o curso está em processo de extinção. Sistema não irá permitir o ingresso de novos alunos.
CursoCampus.extinto Booleano {{ "Sim"|status }} Indica que o curso não possui alunos cursando/ativos.
CursoCampus.exige_enade Booleano {{ "Sim"|status }} Informa se o curso exige registro de ingressante e concluinte do ENADE como requisito obrigatório para conclusão do aluno no curso.
CursoCampus.exige_colacao_grau Booleano {{ "Sim"|status }} Informa se o curso exige registro de colação de grau como requisito obrigatório para conclusão do aluno no curso.
CursoCampus.emite_diploma Booleano {{ "Sim"|status }} Informa se o curso emite diploma/certificado de conclusão.
CursoCampus.assinatura_digital Booleano {{ "Sim"|status }} Informa se o curso emite diploma/certificado de conclusão no formato digital.
Atenção: Esta opção deve ser ativa apenas para os cursos de graduação. Habilita o fluxo de assinatura do diploma via plataforma RapSIgn (RNP).
CursoCampus.assinatura_eletronica Booleano {{ "Sim"|status }} Informa se o curso emite diploma/certificado de conclusão no formato digital.
Atenção: Esta opção pode ser ativada para cursos de modalidades que não sejam de graduação. Habilita o fluxo de assinatura do diploma via fluxo do SUAP

CursoCampus.area_capes Texto {{ "Depende"|status }} Área capes é obrigatório para cursos de especialização, mestrado e doutorado. Obrigatório se modalidade do curso for 9, 10 ou 16.

CursoCampus.codigo_educacenso Texto {{ "Não"|status }} Código EDUCACENSO do curso se houver.

Atenção: Caso no SUAP exista matriz vinculada ao curso e o ID desta matriz não seja informado no CSV, a matriz será removida do curso.
Atenção: Lista separada por vírgula do valor informado na coluna “Matriz.id” no cadastro de matriz.
