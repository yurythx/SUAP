Tipo
Obrigatório
Descrição
Matriz.id Inteiro {{ "Sim"|status }} Identificador único da matriz que será utilizado para identificar os componentes dessa matriz na importação de componentes curriculares. A matriz no SUAP terá o mesmo id.
Matriz.id_estrutura Inteiro {{ "Sim"|status }} Informar 0 (zero) caso não tenha sido cadastrado a estrutura da matriz no SUAP.
Matriz.nivel_ensino Inteiro {{ "Sim"|status }} Nível de ensino da matriz. Valores permitidos:
1: Fundamental
2: Médio
3: Graduação
4: Pós-graduação
Matriz.ativo Booleano {{ "Sim"|status }} Indica se a matriz está ativa.
Matriz.descricao Texto {{ "Sim"|status }} Nome da matriz.
Matriz.data_inicio Data {{ "Sim"|status }} Data de criação/início da matriz. Formato “dd/mm/yyyy”.
Matriz.qtd_periodos_letivos Inteiro {{ "Sim"|status }} Quantidade de períodos letivos da matriz. Mínimo 1 e máximo 12.
Matriz.natureza_participacao Texto {{ "Sim"|status }} Exemplo: Presencial, EAD, Semipresencial.
Matriz.ch_componentes_obrigatorios Inteiro {{ "Sim"|status }} Carga horária de Componentes obrigatórios em hora/relógio.
Matriz.ch_componentes_optativos Inteiro {{ "Sim"|status }} Carga horária de Componentes optativos em hora/relógio.
Matriz.ch_componentes_eletivos Inteiro {{ "Sim"|status }} Carga horária de Componentes eletivos em hora/relógio.
Matriz.ch_seminarios Inteiro {{ "Sim"|status }} Carga horária de Componentes do tipo Seminário em hora/relógio.
Matriz.ch_pratica_profissional Inteiro {{ "Sim"|status }} Carga horária de Componentes do tipo Prática Profissional em hora/relógio.
Matriz.ch_atividades_complementares Inteiro {{ "Sim"|status }} Carga horária de Atividades complementares em hora/relógio.
Matriz.ch_atividades_aprofundamento Inteiro {{ "Sim"|status }} Carga horária de Atividades Teórico-Práticas de Aprofundamento em hora/relógio.
Matriz.ch_componentes_extensao Inteiro {{ "Sim"|status }} Carga horária de Componentes de Atividades de Extensão em hora/relógio.
Matriz.ch_atividades_extensao Inteiro {{ "Sim"|status }} Carga horária total que a matriz possui em atividades de extensão.
Matriz.ch_componentes_com_extensao Inteiro {{ "Sim"|status }} Carga horária de Atividades de Extensão distribuída em componentes de outros tipos em hora/relógio.
Matriz.ch_componentes_tcc Inteiro {{ "Sim"|status }} Carga horária de Componentes do tipo Trabalho de Conclusão de Curso em hora/relógio.
Matriz.ch_pratica_como_componente Inteiro {{ "Sim"|status }} Carga horária de Componentes do tipo Prática como Componente Curricular em hora/relógio.
Matriz.ch_visita_tecnica Inteiro {{ "Sim"|status }} Carga horária de Visita Técnica/Aula de Campo em componentes em hora/relógio.
Matriz.exige_tcc Booleano {{ "Sim"|status }} Indica se a matriz exige o cadastro de TCC na área do aluno.
Matriz.exige_estagio Booleano {{ "Sim"|status }} Indica se a matriz exige o cadastro de estágio do aluno no módulo de estágios.
Matriz.ch_minima_estagio Inteiro {{ "Depende"|status }} Preenchimento obrigatório se no campo "Matriz.exige_estagio" for informado "true". Indica a carga horária mínima de estágio que o aluno deve cumprir. Deve ser vazio se a matriz não exigir estágio.
Matriz.periodo_minimo_estagio_obrigatorio Inteiro {{ "Depende"|status }} Indica a partir de qual período o aluno pode realizar estágio obrigatório. Mínimo 1 e máximo 9. Deve ser vazio se no campo "Matriz.exige_estagio" for informado "false".
Matriz.periodo_minimo_estagio_nao_obrigatorio Inteiro {{ "Depende"|status }} Indica a partir de qual período o aluno pode realizar estágio não obrigatório. Mínimo 1 e máximo 9. Deve ser vazio se no campo "Matriz.exige_estagio" for informado "false".
Matriz.data_fim Data {{ "Não"|status }} Data de inativação da matriz. Formato “dd/mm/yyyy”.
Matriz.observacao Texto {{ "Não"|status }} Campo livre para alguma observação sobre a matriz.
