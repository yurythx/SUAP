Tabela de referência de classes para Barra de Busca e Filtros
Parâmetro Código Descrição
OPTIONAL_CLASS_PARENT large-filters Para fazer com que todos os filtros fiquem com uma largura maior que a padrão.
OPTIONAL_CLASS_CHILD large Para fazer com que o filtro fique com uma largura maior que a padrão.
separator Para exibir um separador visual entre este filtro e o próximo.
show-condition-or Para exibir o texto "ou" entre este filtro e o próximo.
